SOCKS5 через туннель

Порт SOCKS5: TCP 12500 · предусмотрен адаптацией

Слушатель привязывается только к текущему приватному IPv4-адресу downstream-интерфейса eth1: TCP 12500. На 0.0.0.0 и WAN-адрес не открывается. Авторизация SOCKS5 — без пароля. Исходящие TCP/UDP-соединения помечаются для таблицы маршрутизации LaLune (fwmark 0x4d53, table 202).

Проверка фактического состояния слушателя и end-to-end передачи пока не подключена к backend. Карточка описывает целевую конфигурацию, а не подтверждает активность сервиса.

VK и получение хешей

Проверка токена…

Токен используется для режимов «Авто API» и «Авто VK».

Для VK-авторизации на NanoPi ARM64 требуется Chromium. Если он не установлен, выполните на NanoPi: sudo sh /usr/local/lib/lalune/server-assets/install-vk-chromium.sh.

Если автоматический браузерный вход на headless NanoPi не может показать окно VK, откройте OAuth на телефоне/компьютере, войдите и скопируйте конечный URL из адресной строки. В нём будет access_token. Не отправляйте эту ссылку никому.
